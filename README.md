# Bar Truck Build

A used 26 ft box truck that opens into a railed deck and bar. Concept films, an interactive 3D model and the build goals, for makers who want to help.

Live site: https://chuckedson541.github.io/

Max Edson · Eugene, Oregon

## Versions and approvals

Every change starts in **Beta** (branch `beta`, shown at `/beta/`). Moving it to **UAT** (`uat`, shown at `/uat/`) and then to **GA**, the main site (`main`), each waits for Chuck's approval in GitHub (Actions > the waiting run > Review deployments > Approve). Beta and UAT pages carry a colored banner and are hidden from search engines. Skipping UAT is possible only with the "EMERGENCY Beta -> GA" workflow, which also needs approval.
